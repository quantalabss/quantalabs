quantakrypto — brand assets
================================

The lattice mark: two indigo basis vectors (b1, b2) and the single red shortest
vector (lambda-1) from an ink origin — the hard problem at the heart of lattice
cryptography. Free to use when referring to quantakrypto.

Files (SVG scales infinitely; PNG exported at 3x for slides and profile pictures):
  quantakrypto-logo-light      mark + wordmark, on light backgrounds
  quantakrypto-logo-dark       mark + wordmark, on dark backgrounds
  quantakrypto-mark            the lattice glyph, in colour
  quantakrypto-mark-ink        the glyph in a single ink colour (light bg)
  quantakrypto-mark-white      the glyph in white (dark bg)
  quantakrypto-avatar-light    profile picture, paper tile
  quantakrypto-avatar-dark     profile picture, ink tile

Palette:
  Indigo      #4733E0   primary / action
  Signal red  #E0364D   the hard problem / threat
  Ink         #0E1626   text
  Paper       #EAEDF2   background
  Muted       #5B6678   secondary text
  Grid        #CDD4DF   hairlines

Do: keep clear space around the mark equal to the origin dot; use the colour mark
on light, the white mark on dark; prefer the SVG. The wordmark is Bricolage Grotesque.
Don't: recolour the mark, change the vector angles, add shadows/gradients/outlines,
or stretch, rotate, or crop it.
